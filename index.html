VALORANT stats.
Right in Twitch chat.

VALORANT StreamElements is a Twitch bot project that makes player statistics and match information easy to access during a stream. The goal is simple: help players and communities explore their VALORANT performance without leaving chat.

In development · Public release planned
About the project

Built for players, streamers, and their communities.

The project started as a personal tool for my Twitch channel. Friends and other players have also shown interest, so the plan is to make it publicly available and useful to a wider VALORANT community.

One of the main goals is to provide broader career statistics, ideally covering a player's match history from the earliest data available—not only a small recent sample. Data coverage will depend on the official API access and the match history Riot makes available.

Planned and existing features

Useful information, one command away.

The bot is being developed around straightforward commands for common player-stat requests. Available features may evolve as the project develops.

!rank!season!ultimapartita!record!statistiche
Current focus: improving the reliability and coverage of overall statistics, while keeping the bot easy to use and suitable for a public release.
Development approach

Reliable data, transparent scope.

Use authorized data sources

The project aims to integrate Riot Games APIs in accordance with Riot's developer policies and access requirements.

Make stats understandable

Present match and career information in a concise format that works naturally in a live Twitch chat.

Grow responsibly

Test the bot, document its behavior, and prepare it for wider community use as approvals and implementation allow.
